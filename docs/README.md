## Figures

Generated by scripts under [`../f1sim/scripts/`](../f1sim/scripts/) and checked in for reference:
track galleries (`tracks_*.png`, `map_grid.png`, `map_zoo.png`), racelines (`racelines.png`,
`raceline_1.png`), real venues (`real_venues.png`, `real_maps_*.png`, `korea_team_maps.png`),
multi-car LiDAR (`multicar_lidar.png`), an IMU trace (`imu_trace.png`) and a single lap
(`track_1_lap.png`). `tracks_info.json` holds the catalogue metadata behind the galleries.

Rendered video (`promo.gif`, `promo.mp4`) can be regenerated with `f1sim/scripts/promo_video.py`.
