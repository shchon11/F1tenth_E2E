# 횡방향 차량 모델 재식별 + bag_profile (2026-11-28)

담당(Opus)의 결과 요약을 PM이 옮겨 적은 것입니다. 재현 스크립트와 결과 json은 `tools/`, 그림은 `figs/`, bag_profile 출력 예시는 `examples/`, 현장 측정 절차는 `FIELD_PROTOCOL.md`에 있습니다.

## 결론

시뮬 코드에 값만 다시 맞춘 구조(c2*)가 미리 정한 채택 기준을 통과했습니다. 최종 확인 bag에서 시뮬의 가짜 스핀이 13.3 %에서 0 %로 줄었고, 2초 뒤 위치 오차가 1.00 m에서 0.45 m로 줄어 값 4개짜리 단순 모델(0.46 m)과 같은 수준이 됐습니다. 기존 기본값은 바꾸지 않았고 새 프로필 파일로만 제공합니다.

## 구조 비교 (최종 확인 bag 3개, 874구간, 한 번만 평가)

| 모델 | 1 s 요레이트 [rad/s] | 2 s 위치 [m] | 한계 근처 1 s 요레이트 | 스핀 비율 |
|---|---|---|---|---|
| 감사의 4값 단순 모델 | 0.147 | 0.46 | 0.191 | 0 % |
| 단일트랙 + 포화 타이어, numpy 구현 (b') | 0.121 | 0.38 | 0.145 | 0 % |
| 시뮬 명목 (전) | 0.188 | 1.00 | 0.268 | 13.3 % |
| (c2*) 시뮬 코드에 값만 다시 맞춤 (후, 채택) | 0.136 | 0.45 | 0.162 | 0 % |

- 종방향 하중 이동을 넣은 두 후보는 학습·검증·최종 모두에서 더 나빴습니다.
- 채택 기준은 최종 평가 전에 `tools/common.py`에 고정. 2 s 위치 p90만 1.21 대 1.14 m로 단순 모델보다 약간 나쁨.

## 스핀의 원인

시뮬의 종방향 하중 이동이 하중에 비례하는 타이어와 겹쳐 생긴 가짜 스핀. 프로필에서 무게중심 높이 h를 0으로 두고 접촉 높이를 같은 0.074 m만큼 내려 접촉 시 롤·피치 응답은 보존. 실차가 안 미끄러진 구간에서 시뮬이 스핀한 비율: 최종 확인 11.4 → 0 %, 한계 근처 18.4 → 0 %, 검증 12.4 → 0 %.

타이어 곡선은 데이터가 쓴 미끄럼각 범위(앞 22°, 뒤 13° 이하)에서 앞은 거의 선형, 뒤는 부드럽게 포화. 모델 최대 횡가속 약 1.35 g(실차가 버틴 값 0.98 g보다 위 — 한계 그립의 상한은 데이터에 없음).

## 장소를 옮길 때

다시 맞출 값은 직진 보정(트림)과 순수 지연 두 개. 이것만 맞춰도 새 장소 held-out 1 s 요레이트 0.105로, 8개를 전부 다시 맞춘 0.110과 같음. 새 장소 주행 약 10 s면 충분.

## 기본 프로필 = 대회 차의 차 값 + 대회 이전 장소의 장소 값

- 조합 타당성: 차 값만 바꾼 시뮬이 사전 장소 held-out을 맞춤(map12x16에서 요레이트 0.187 → 0.119, 2 s 위치 0.54 → 0.33 m).
- 사전 bag에서 뽑히는 장소 값: 그립 하한 0.88 g, 단 한 번의 실제 스핀에서 나온 마찰 약 1.0(약한 근거).
- 세 사전 장소는 장소 값으로 구분되지 않음.
- 값별 출처·불확실도와 "필요할 때 잴 목록": `f1sim/f1sim/profiles/default_comp_car_pre_place.yaml`.

## bag_profile (`python -m f1sim.bag_profile <bag> --out <폴더>`)

같은 장소 bag 사이에서 재현되고 두 차 설정을 겹침 없이 구분하는 값:

| 값 | 대회 차 (bag 11~12개) | 사전 차 |
|---|---|---|
| 서보 변환식 | 0.630·δ + 0.395 | −0.530·δ + 0.605 |
| 서보 창 | −0.254 / +0.412 rad | 오른쪽 −0.311 |
| ERPM 이득 | 4204 | 4514 |
| 회생 전류 | −30 A | −5 A |
| 지연(4값 모델) | 0.10 [0.09, 0.11] s | 0.16 s |
| 트림 | −0.021 | −0.010 |
| 제동 한계 | 4.8 [4.4, 5.2] m/s² | — |

그 밖에 자이로 단위(7월 bag은 deg/s), 버틴 최대 횡가속(그립 하한), LiDAR 장착 위치와 정지 잡음 4.4 mm, 지도 축척 1.000 [0.993, 1.014].

못 내는 값: 최대 마찰의 상한, 타이어 모양, 저항, 질량·관성. bag 하나의 강성 판정은 구간 수가 적으면 흔들리므로 장소 단위로 묶어서 볼 것.

## 주행 중 적응 가능성

트림과 지연은 10~20 s 주행으로 실시간 추정 가능. 그립 정보는 횡가속 8 m/s² 이상 구간에만 있음 — 한계에 가지 않으면 하한만 갱신됨.

## 새로 녹화해야 정해지는 것 (필요할 때)

1. 사전 장소에서 일정 반경 속도 램프: 최대 마찰, 한계에서 앞·뒤 중 어느 쪽이 먼저 빠지는지.
2. 대회 차로 사전 장소 레이스 랩: 조합 기본 프로필을 직접 검증할 bag이 지금 없음.
3. 저속 원선회 + 바퀴 각 측정: 조향 이득의 절댓값.
4. 코스트다운: 구름·공기 저항.
5. 조향 처프: 순수 지연과 서보 지연 분리.
6. 저울·매달기: 질량, 무게중심, 요 관성.
