# TENTH 화면 규격 (3차 · A안 문법)

2026-11-29 · 대상: `out/01_main.png` ~ `out/18_records.png` (1920×1200) · 원본: 같은 이름의 `.html` + `assets/base.css` · 한 장 훑어보기: `overview.png`

목업은 `tools/build.py`가 기록 파일에서 값을 읽어 만든 정적 HTML이다(스크립트 없음). 장면은 `tools/scene3.py`가 CPU로 그린 정지 그림이고, 실제 앱에서는 Godot이 같은 차 모델(`f1tenth_car.glb`)과 같은 지도를 그린다.

## 1. 문법 (어느 화면에서나 같음)

1. 3D 장면이 화면 전체다. 판·카드·테두리 상자를 쓰지 않는다.
2. 조작하는 것은 모두 왼쪽 한 기둥(x 60~696)에 세로로 쌓는다. 주행 중만 예외다(§6).
3. 한 화면에 흰색으로 채운 것은 하나다: 낱말 목록의 초점 띠, 또는 주 버튼.
4. 값은 그 줄에서 좌우로 바꾼다. 바꾸면 장면이 바로 따라 바뀐다.
5. 글은 이름표와 값뿐이다. 문장, 도움말 줄, 범례, 줄마다 붙는 딱지를 쓰지 않는다.
6. 자세한 것은 고른 줄에서만 펼친다(값의 범위와 출처, 한 바퀴의 접촉).
7. 지금 고른 것의 값은 오른쪽 위에 이름표 작게, 값 크게, 상자 없이 둔다.
8. 글꼴 한 가족(Pretendard), 강조색 없음. 색은 장면에서만 나온다.

## 4. 초점 이동

1. 위·아래: 기둥 안에서만 움직인다. 목록 끝에서 처음으로 넘어간다. 순서는 줄 → 주 버튼 → 보조 낱말.
2. 좌·우: 값 줄에서는 값을 바꾼다. 보조 낱말 줄에서는 낱말 사이를 옮긴다. 그 밖에는 아무 일도 없다.
3. 확인(Enter / Ⓐ): 초점 항목을 실행한다. 값 줄에서는 고르는 창 없이 다음 값으로 넘어간다.
4. 뒤로(Esc / Ⓑ): 화면에 "뒤로" 낱말이 늘 있고, 같은 일을 한다.
5. 주 버튼 바로 가기(Space / 시작 버튼): 초점이 어디 있든 그 화면의 주 버튼을 누른다. 2차 안에서 남았던 "값을 바꾼 뒤 출발까지 내려가는 길이 길다"를 이것으로 푼다.
6. 들어올 때의 초점: 주 버튼이 있으면 주 버튼(레이스 준비, 결과, 가져오기, 기록), 없으면 지금 고른 항목(코스·훈련 목록) 또는 첫 줄.
7. 마우스: 올리면 초점, 누르면 실행. 값 줄에서는 화살표를 누르거나 휠을 돌린다.
8. 주행 중: 층 켜고 끄기는 숫자 키 1~5(미니맵, LiDAR, 드라이버 궤적, 조향·가감속, 바퀴 기록), 또는 일시정지 → 표시. 키 이름은 화면에 쓰지 않는다.

## 6. 주행 HUD

**기본으로 보이는 것 세 덩어리.**

| 자리 | 내용 | 까닭 |
|---|---|---|
| 왼쪽 위 | 무충돌 연속 · 최고 랩 · 이번 랩 | 앞의 둘이 예선 점수다. 이번 랩은 최고 랩과 견줘 읽으므로 옆에 둔다 |
| 가운데 위 | 남은 시간 + 세션 줄(지나온 만큼 채워짐, "상자 치움" 눈금) | 세션이 시간으로 끝나고, 상자가 치워지는 때가 그 줄 위의 한 점이다 |
| 가운데 아래 | 속도(m/s) | 차 바로 아래, 눈이 가장 덜 움직이는 자리 |

**층 다섯.** 미니맵(오른쪽 위), 바퀴 기록(점수 아래에 이어 붙음), 조향·가감속(속도 양옆), LiDAR와 드라이버 궤적(장면 안). 다 켜도 네 무리로 읽히게 기본 덩어리에 붙여 놓는다. 조향 막대는 서보 창이 한쪽으로 치우친 그대로 그린다(왼쪽 +0.412, 오른쪽 −0.254 rad, 0은 가운데가 아님).

**상자가 치워질 때.** 세션 줄이 눈금에 닿는 순간 가운데에 "상자 치움"이 2 s 뜨고, 장면의 상자가 0.6 s에 걸쳐 사라진다. 미니맵이 켜져 있으면 상자 점도 같이 사라진다.

"무충돌 연속"은 주행 중에는 지금 이어지는 수(닿으면 0), 결과에서는 세션 최고다.
