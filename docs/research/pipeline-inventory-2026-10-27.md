# 학습에 들어 있는 것 전부: 무엇이고, 왜 있고, 근거가 있나 (2026-10-27)

사용자: "지금 학습방법도 존나 잡탕이고 선생도 뭐 뭔지도 모르겠고." 맞는 말이라 정리합니다. 새 장치를 더 붙이기 전에, 지금 있는 것을 하나씩 근거로 걸러 내려는 목록입니다.

## 2. 지금 대회 정책이 만들어진 순서

1. 주행선 교사(선형 계획 + iLQR 추종)로 모방 학습 → 몇 주의 강화 학습(혼자 단계, 경주 단계, 부트캠프) → 옛 Korea 정책 `korea26_rep_s2001_u256`.
2. 새 출력 형식(웨이포인트 4개)으로 옮기려고, **옛 정책을 정책 교사로** Korea + 변형 16개에서 모방 학습(`v2PT_s2362`, 8회).
3. 강화 학습 512회(`v2PH_s2421`): 4대 경주 + 리그, MAP, 대표 바닥, 그립 다이얼 고정, 라그랑주 80 고정, 속도 상한 9.
4. 앞차 판단 머리만 느린 차로 다시 학습(`_nearcar_slow`).

직선 천장(6.5 m/s)은 2단계에서 옛 정책에게서 물려받았고, 3단계가 풀지 못했습니다.

## 4. 오늘 연구로 확인한 것

- **강화 학습은 모든 구간을 같이 느리게 만듭니다**(H2). 모방 학습 끝(혼자 9.32 s)에서 시작한 Korea 강화 학습에서, 구간별 속도 변화는 64회 뒤 −2~−6 %, 512회 뒤 급코너 −20 %, 직선 −18 %였습니다. 아무것도 부딪히지 않는 직선까지 느려졌습니다.
- 상자 때문은 아닙니다. 상자 없이 해도 같이 느려졌습니다(128회 뒤 9.84 s, 상자 라인 위 9.86 s).
- 진행 중(H1): 느려진 대가로 실제로 덜 부딪히게 됐는지, 같은 경주 조건(상대 4종 × 시드 2개)으로 학습 전과 512회 뒤를 잽니다.
