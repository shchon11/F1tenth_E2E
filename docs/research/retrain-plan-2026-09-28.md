# 새 시뮬 재학습 계획 (2026-09-28)

지금까지의 모든 체크포인트는 보정 전 시뮬에서 학습됐다(`sim-realism-2026-09-28.md`).
보정된 시뮬에서 c2는 랩 7.88 → 8.24 s, 레이스 충돌 3.40 → 4.90/km로 나빠진다.
합의된 구조(범용 DAgger → 맵별 PPO)는 그대로 두고, 새 시뮬에서 두 단계를 다시 한다.

## 1단계: 범용 DAgger (모든 학습 트랙, 상대 포함)

- **시작점:** `checkpoints/dial_student_s901.pt`(옛 시뮬 범용 학생). DAgger는 매 반복 새 시뮬에서 다시 라벨을 달기 때문에 이어서 학습해도 새 동역학에 맞춰진다.
- **설정:** 이전 `dagger_general.sh`와 같다(학습 트랙 149개, 최소곡률 라인, 상대 4종, 다이얼 조건).
- **바뀐 것:** 새 시뮬 기본값. 추종기·선생 k_us 0.02가 포함된다.
- **라인:** 최소곡률 라인은 트랙당 1.5~5초면 만들어진다(최소시간 라인은 CPU 4코어에서 약 25시간이라 쓰지 않는다).
- **사전 판정** (새 시뮬, 평가 트랙에서 rt:Monza·real:map16x07 제외, 시드 2개):
  완주율 ≥ dial_student_s901(새 시뮬에서 잰 값), 충돌/km ≤ 그 값.

## 2단계: ICCAS PPO

- **시작점:** 1단계 학생.
- **레시피:** c2 레시피(GRU + 보조 예측, 추돌 Δv² 4, 합류 20)에 다음을 더한다.
  - **상대 집단(리그):** 과거 체크포인트(s915u768, c2, c3, mem940) + 자기 자신 + 계획기 4종. 상대 이벤트(차선 변경·막기·급감속)와 반응 성향을 켠다.
  - **GAE λ 0.95 → 0.97:** 물러섰다 나중에 추월하는 이득은 2~3초 뒤에 온다. λ 0.95는 이득 계산이 사실상 약 0.5초 앞까지만 반영돼서 이 행동을 배우기 어렵다.
  - **실수 지점 재시작:** `--replay-contacts`.
- **학습 전 검증:** 리그 설정으로 상황 조사(census)를 한다. 근접 상황이 km당 늘지 않으면 학습하지 않는다.
- **사전 판정** (시드 77~80 × 상대 4종, 새 시뮬):
  - 차 접촉: c2(새 시뮬, k_us 0.02) 대비 −25 % 이상
  - 추월: 90 % 이상 유지
  - 혼자 주행 랩과 장애물 접촉: 5 % 이상 악화 없음
  - 접촉 유형별로 "이른 합류"(35 %)와 "내가 추돌"(22 %)을 따로 본다.

## 나머지 작업의 위치

- **플래너 속도 출력:** 새 차 기준 이득이 약 4 %라 이번 재학습에서는 행동 공간을 바꾸지 않는다. 정책의 v1 ≈ 0 출력은 2단계 뒤에 다시 잰다.
- **노면 감지:** 반증 실험 1번의 결과로 정한다(`grip-sensing-references-2026-09-28.md`). 실패하면 다이얼을 유지한다.
- **시뮬 미결:** 상대차 겉보기 폭, 횡하중이동, 타이어 이완. 실측 데이터가 생기면 반영한다.
