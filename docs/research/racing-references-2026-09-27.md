# 상대차 대응: 레퍼런스 정독과 우리 시스템 대조 (2026-09-27)

이번 주 상대차 실험(롤아웃 선생 DAgger, 후보 채점기, 모델 기반 선택기)이 모두 정책의 상대 대응을 올리지 못한 뒤,
관련 연구 10편을 본문까지 읽고 우리 설정과 1:1로 대조했다. 수치는 각 논문 원문 값이다.

## 1. 읽은 것

| 논문 | 요지 |
|---|---|
| GT Sophy (Nature 2022) | QR-SAC, 4×2048 MLP(메모리 없음), 상대 앞·뒤 목록의 상대 위치·속도·가속도를 명시 입력. 보상에 대칭 추월항(0.5)·과실 무관 충돌(−5/스텝)·추돌 Δv²·비신사적 접촉. 1v0~1v7·slipstream·grid 시나리오를 동시에, 미니배치마다 비율 고정. 상대는 이전 정책 + 게임 AI + 라인 지정 PID. 실수 직전 상태를 새 시작점으로. 주행 45,000시간 이상 |
| Vision GT (RLC 2024) | 64×64 영상, critic만 코스 정보(비대칭 actor-critic). 상대 없음 |
| End2Race (2025) | LiDAR 180빔, 근거리 강조 시그모이드 정규화, GRU(420), lattice 선생으로 BC 후 PPO. 상대 속도 0.4~0.8배, 고정 라인, 3 m 뒤 시작. PPO 후 안전 98.1% / 추월 96.1%(BC 82.8/62.8). 반응형 상대에게 안전 91.7% |
| F1TENTH RL 추월 (2025) | TD3, LiDAR 10값. 상대와 함께 학습하면 추월 88%/87%(시뮬/실차), 혼자 학습하면 55%/56%. 추월 보상은 reward hacking이라 뺌 |
| LiDAR E2E RL (2023) | 4프레임 스택, 정적 장애물만 |
| RL 추월 궤적계획 (2024) | 명시 상태, 반응형 blocker. 공격성 3종으로 학습하면 가장 공격적인 상대에게도 90% 이상, 1종이면 급락. 예측 후 계획 방식은 공격적 blocker에 최대 30% |
| TAL (2023) | 선생 행동과의 차이를 보상으로 |
| Predictive Spliner (2024) | 상대 라인을 1랩 관찰해 GP로 예측, 충돌 구간 안에서만 회피. 추월/(추월+충돌) 57% → 84.5% |
| SGTP (2026) | 게임이론 샘플링(K=128, 1.2 s, IBR 2회). 충돌은 비용이 아니라 **제약으로 걸러야** 함(가중평균 방식 충돌 없는 승리 0%, 거르는 방식 100%) |
| Deep Latent Competition (2020) | 두 차의 잠재 동역학을 함께 학습, 상상 self-play |

## 2. 우리 시스템과 대조

| 항목 | 레퍼런스 | 우리 (s915 계열) |
|---|---|---|
| 실수 지점 재시작 | Sophy | 없음 → **추가함**(`--replay-contacts`) |
| 상대 행동 다양성 | Sophy·논문 4: 결정적 | 계획기 4종. 라인 변경·막기·급감속 이벤트와 반응 성향은 **꺼져 있음** |
| 상대 속도 | 0.4~0.8(End2Race), 0.75(논문 2) | 0.7~1.0 |
| 메모리 | End2Race GRU(안전 +12%p), Sophy는 상대 속도·가속도 명시 입력 | 둘 다 없음. 다이얼과 GRU를 함께 못 쓰게 막혀 있었음 → **풀었음** |
| LiDAR 정규화 | 근거리 강조 시그모이드(BC 추월 63% 대 선형 47%) | 선형 /10 m |
| 추월 보상 | 대칭 밀집(Sophy), 일회성은 hacking | 밀집(아크 이득 비례) |
| 충돌 비용 | 과실 무관 −5/스텝 + 추돌 Δv²(Sophy) | 시작 8 + 8×속도, 접촉 중 스텝당 5(내 책임일 때) |
| 실행 시 충돌 방지 | 제약으로 거르기(SGTP) | 없음(선택기 실험은 등속 예측이라 −14%) |
| 학습 규모 | 45,000시간 이상(Sophy) | 약 2800만 스텝 |

## 3. 공통 교훈

GT Sophy도 상대의 정답 상태를 입력으로 받았지만, **보상 설계·상대 집단·시나리오 구성**이 없으면 지나치게 공격적이거나
소심해졌다. 09-15에 상대 토큰을 줘도 정책이 쓰지 않은 것과 같은 현상이다. 정보가 아니라 **학습 환경의 구성**이 행동을 정한다.
또 라인을 바꾸거나 막는 상대를 LiDAR E2E 정책으로 검증한 논문은 없다. 우리가 막힌 문제가 연구에서도 열린 문제다.

## 4. 이어지는 실험

1. `spec_korea_mem_s940`: s915u768 + GRU + 상대 보조 예측(`--aux-future 1.0 --aux-opp 0.5`). 판정: 두 시드 × 상대 4종에서
   차 접촉 −30% 이상, 추월 감소 10% 이내, 혼자 주행 랩·장애물 접촉 악화 5% 이내.
2. 다음 PPO: 실수 지점 재시작(`--replay-contacts`), 상대 이벤트·반응 성향 켜기, 상대 속도 0.5~1.05.
3. 전체 재학습(범용 DAgger부터)은 1·2로 효과가 확인된 요소만 넣어서. LiDAR 정규화 변경은 그때 함께.
