# 실차 명령 리플레이: 시뮬은 같은 조향에 25~42 % 더 돈다 (2026-09-28)

## 방법

- 데이터: 대회 백 11개(`map08x23`, ForzaETH 스택 자율주행)를 1초 구간 928개로 잘랐다.
- 제외한 구간: 속도 1.5 m/s 미만, 서보가 조향 한계에 붙은 순간, 충격 앞뒤 1초.
- 초기화: 각 구간 시작의 속도(휠 속도), 요레이트(자이로), 조향으로 시뮬 차를 초기화했다.
- 재생: 실차가 받은 `/drive` 명령(조향각, 속도)을 40 Hz로 그대로 넣었다.
- 바닥: 가장자리만 벽인 80 m 정사각 빈 바닥. 트랙 격자 밖은 벽으로 처리되므로 빈 바닥이 필요하다.
- 비교: 시뮬 요레이트와 속도를 실측과 비교했다. 처음 0.25초는 초기 횡속도를 모르므로 채점에서 뺐다.
- 스크립트: `f1sim/scripts/replay_dynamics.py`.

## 결과

기본 시뮬(랜덤화 끔, μ 1.0489)에서 시뮬/실차 요레이트 비율(중앙값):

| 조건 | 비율 |
|---|---|
| 횡가속 0~3 / 3~6 / 6~8 / 8+ m/s² | 1.26 / 1.29 / 1.33 / 1.18 |
| 속도 1.5~3 / 3~4.5 / 4.5~6 / 6~9.5 m/s (횡가속 < 5) | 1.25 / 1.33 / 1.39 / 1.42 |

- **저속에서도 1.25배**다. 실제 바퀴가 명령보다 덜 꺾인다(조향 게인 < 1).
- **속도가 오를수록 커진다.** 실차가 더 언더스티어한다(타이어 선형 강성이 더 작다).
- **자이로는 정상이다.** 가속도계와 상관 0.82~0.94이고, v·r이 가속도계보다 약 10 % 크게 읽힌다. 측정 오차가 있더라도 실차 회전을 과대평가하는 방향이라 결론은 바뀌지 않는다.
- `servo_tau` 0.12(09-21 감사 권고)는 비율을 거의 바꾸지 않았다(1.29 → 1.30). 진폭 초과는 지연이 아니라 게인·강성 문제다.

격자 탐색(조향 게인 × Pacejka B 배율):

| steer_gain | B 배율 | 요레이트 RMSE | 속도별 비율 |
|---|---|---|---|
| 1.0 (기본) | 1.0 | 0.40 이상 | 1.25~1.42 |
| 0.8 | 0.6 | 0.306 | 0.97 / 1.05 / 1.09 / 1.10 |
| 0.75 | 0.6 | 0.293 | 0.91 / 1.00 / 1.04 / 1.06 |

실차는 **조향 게인 약 0.75~0.8, 타이어 강성 B 약 0.6배**에 맞는다. 현재 랜덤화 범위(조향 게인 0.92~1.08, B 0.8~1.2배)는 둘 다 덮지 못한다.

## 주의와 미결

- 노면 하나, ForzaETH 명령 분포, 1초 개루프 구간, 두 파라미터 적합이다. 횡하중이동이나 "μ가 강성까지 바꾼다" 구조는 이 적합에 들어 있지 않다.
- 사용자는 Roboracer 원호 방식으로 조향을 캘리브레이션했다. 그렇다면 저속 비율이 1에 가까워야 해서 결과와 충돌한다.
  차에서 확인할 방법: 1 m/s로 0.2 rad를 명령하고 원을 잰다. 명령대로면 반지름 1.63 m, 게인 0.8이면 약 2.0 m다.
