# 실측 bag으로 시뮬 물리 다시 확인 (2026-11-09)

사용자: "실제 주행한 백으로는 확실히 확인할 수 있는거 없는거 구분해서 반영해봐. 실측백 있잖아. 기존 측정했던거 믿지 말고 네가 새로 직접 다시 확인해."

예전 측정(09-21 감사, 09-28 재생, `real_data/README.md`의 주장)은 쓰지 않고, bag에서 처음부터 다시 쟀다.

## 자료

- `real_data/01_competition_0826-0827_map08x23`: 대회장, bag 13개. 그중 주행 bag 12개, 주행 875초.
- `02_pre-competition`: 다른 바닥이라 맞춤에는 쓰지 않았다.
- 추출: `tools/bag_extract.py`, `tools/extract_all.sh` → `/data/sim2real_1109/*.npz`
- 공통 신호(100 Hz): `tools/s2r_signals.py`
- 명령은 VESC가 실제로 받은 `/commands/servo/position`과 `/commands/motor/speed`를 썼다.
  - `/drive`와 다른 때는 주행의 1~2 %로, 조이스틱 전환 순간이다.

## 확인할 수 없는 것

- **타이어 최대 마찰**: 차가 0.3초 동안 유지한 옆 가속은 최대 8.9 m/s²였다(자이로·IMU 둘 다). 8 이상을 유지한 시간은 875초 중 0.7초뿐이다. 그래서 하한만 알 수 있다. 시뮬의 정상 상태 최대는 8.0~8.4다.
- **기계적 최대 조향각**: 끝까지 꺾은 표본은 모두 3~3.6 m/s, 옆 가속 6~7 m/s²에서 나왔다. 이 영역은 타이어 한계가 정하므로 각도를 따로 알 수 없다.
- **조향 이득과 앞 타이어 강성 각각의 값**: 서로 맞바꿔진다(위 골짜기). 곱해진 효과만 정해진다.
- **명령 지연과 서보 시간 상수 각각의 값**: 합만 정해진다.
- **서보 최대 속도 sv_max**: 1.5~10 rad/s 모두 오차가 3 % 안이다.
- **질량, Iz**: Iz 0.035~0.06은 모두 비슷하다. 질량을 잴 힘 측정이 없다.
- **우리 스택의 추론 지연과 스캔 전송 지연**: urg 드라이버가 스캔 시각을 스스로 찍어서 bag에서는 알 수 없다. `/drive` 이후의 0.03초만 쟀다.
- **VESC 속도 루프의 내부 구조**:
  - 실차는 정속에서 속도가 처지지 않는다. 시뮬의 1차 지연 루프는 1초에 약 0.15 m/s 처진다.
  - 실차는 같은 속도 오차에서 시뮬보다 약하게 제동한다(회생 한계에 닿는 것은 15 %).
  - 적분(PI)과 제동 쪽 시간 상수 모델은 단순 이득 보정(1.04)보다 낫지 않았다. 그래서 구조를 정하지 못했고 바꾸지 않았다.
